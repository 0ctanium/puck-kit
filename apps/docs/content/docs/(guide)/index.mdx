**puck-kit** turns [Puck](https://puckeditor.com) into a visual site builder in the spirit of Webflow:
instead of rigid, pre-designed blocks, you get **generic HTML elements** (sections, containers, flex,
grid, headings, links, images…) that editors nest freely and style with a **responsive style panel**.

<Screenshot
  src="editor-overview.png"
  alt="The Puck editor with puck-kit: component drawer, canvas, breakpoint switcher and style panel"
  variant="browser"
  caption="The Puck editor with the puck-kit plugin: compact component drawer, canvas and Style tab."
/>

Styles compile to **plain CSS at render time**: no Tailwind, no build step, and no client-side
JavaScript on public pages. The page you publish is just Puck's `<Render>` output and a few
`<style>` tags hoisted to `<head>`.

## A taste

One shared config, Puck's own editor with the kit's plugin, and Puck's own `<Render>` on the public page:

<Tabs items={['config.ts', 'Editor.tsx', 'page.tsx']}>
<Tab value="config.ts">

```ts title="lib/config.ts"
import { createBuilderConfig } from 'puck-kit';

export const config = createBuilderConfig();
```

</Tab>
<Tab value="Editor.tsx">

```tsx title="app/edit/Editor.tsx"
'use client';
import { Puck, type Data } from '@puckeditor/core';
import '@puckeditor/core/puck.css';
import { usePuckKit } from 'puck-kit/editor';
import { config } from '@/lib/config';

export function Editor({ data }: { data: Data }) {
  const kit = usePuckKit(config); // { plugins, viewports, ui }
  return <Puck config={config} data={data} {...kit} onPublish={save} />;
}
```

</Tab>
<Tab value="page.tsx">

```tsx title="app/[slug]/page.tsx"
import { Render } from '@puckeditor/core';
import { config } from '@/lib/config';

export default async function Page() {
  const data = await loadPage(); // your storage
  return <Render config={config} data={data} />;
}
```
