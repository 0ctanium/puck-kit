The Style tab is Webflow-like: compact rows, visual controls, and popovers for anything complex.

<Screenshot src="style-breakpoints.png" alt="Breakpoint bar, state selector and legend at the top of the style panel" caption="Top of the panel: breakpoint bar, State, and the set / inherited legend." variant="panel" maxWidth={400} />

## Reading the panel

- The **breakpoint bar** is synced with the switcher in the editor header. A dot marks breakpoints that have
  styles; the bar underneath shows which breakpoints the active one also styles.
- **Blue label** = set on this breakpoint (click it to reset). **Orange label** = inherited (from Desktop, or
  from Tablet on Mobile).
- **Scrub**: drag a label (or a spacing value) left/right to change a number. **Arrow keys** nudge numbers
  (Shift ×10, Alt ×0.1).
- Section headers show a **count** of properties set.
- Dropdowns are keyboard-friendly (↑ ↓ Enter Esc, type to jump) and show icons where they help: position,
  cursor, aspect-ratio shapes, object-fit diagrams, easing curves, filters, font samples.

## Limit the sections

For simple custom components, show only what makes sense:

```ts
styleField({ sections: ['spacing', 'size', 'border'] });
```

## The Advanced section

Below the style sections, **Advanced** (the `advanced` prop) sets an **HTML id**, **extra classes** and an
**ARIA label**. Extra classes are sanitized (only letters, digits, `_`, `-` and spaces are kept).
