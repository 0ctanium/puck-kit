**List** renders a real `<ul>` (bulleted) or `<ol>` (numbered) and **only accepts [List Items](/docs/components/list-item)** (`allow: ["ListItem"]`), so the HTML stays valid: `ul > li`, never `ul > div`.

## Tips

- For a simple bulleted list inside text, the rich text of [Text](/docs/components/text) is quicker. Use List when items need their own layout (icon + text, cards…).
- Turn the list into a flex row or a grid with the Layout section: the items are direct children.
