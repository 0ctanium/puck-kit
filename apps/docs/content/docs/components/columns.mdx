**Columns** renders a grid whose **columns are separate drop zones**. Add or remove columns in the Settings tab (1 to 12); the column template follows the count automatically, and the columns stack on phone-sized breakpoints.

## Default styles

A freshly dropped Columns starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "display": "grid",
    "gap": "24px",
    "gridTemplateColumns": "repeat(2,minmax(0,1fr))"
  },
  "mobile": {
    "gridTemplateColumns": "minmax(0,1fr)"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  display: grid;
  gap: 24px;
  grid-template-columns: repeat(2,minmax(0,1fr));
}
@media (max-width:767px) {
  .pk-id {
    grid-template-columns: minmax(0,1fr);
  }
}
```

</Tab>
</Tabs>

The stacked template goes on every breakpoint whose editor viewport is narrower than 768px (`mobile` by default).

## Tips

- While the template is an equal `repeat(N,minmax(0,1fr))`, adding or removing a column updates it (`resolveData`). Once you customize it (e.g. `2fr 1fr`), the kit leaves it alone.
- Column wrappers get `min-width: 0` so wide content (code, images) can’t blow up the layout.
