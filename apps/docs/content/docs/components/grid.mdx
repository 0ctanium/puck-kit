**Grid** is a Box preset with `display: grid`, two equal columns and two auto rows. The Layout section turns into a **visual grid editor**: steppers for columns and rows, and a popover to size each track in `fr`, `px` or `auto`. Children get a **Grid child** section to span cells.

## Default styles

A freshly dropped Grid starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "display": "grid",
    "gridTemplateColumns": "repeat(2,minmax(0,1fr))",
    "gridTemplateRows": "auto auto",
    "gap": "16px"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  display: grid;
  grid-template-columns: repeat(2,minmax(0,1fr));
  grid-template-rows: auto auto;
  gap: 16px;
}
```

## Tips

- Columns use `minmax(0, …fr)` so long content can’t overflow its track.
- Prefer [Columns](/docs/components/columns) when each column holds its own content stack; use Grid for cards, galleries and bento layouts.
