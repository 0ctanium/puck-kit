A **Container** centers its content with automatic side margins and limits its width **per breakpoint**. Its defaults are computed from your breakpoints, so they adapt to any setup (desktop-first, mobile-first or custom).

## Default styles

A freshly dropped Container starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "width": "100%",
    "marginLeft": "auto",
    "marginRight": "auto",
    "paddingLeft": "16px",
    "paddingRight": "16px",
    "maxWidth": "960px"
  },
  "wide": {
    "maxWidth": "1200px"
  },
  "tablet": {
    "maxWidth": "728px"
  },
  "mobile": {
    "maxWidth": "none"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  width: 100%;
  margin-left: auto;
  margin-right: auto;
  padding-left: 16px;
  padding-right: 16px;
  max-width: 960px;
}
@media (min-width:1280px) {
  .pk-id {
    max-width: 1200px;
  }
}
@media (max-width:1023px) {
  .pk-id {
    max-width: 728px;
  }
}
@media (max-width:767px) {
  .pk-id {
    max-width: none;
  }
}
```

</Tab>
</Tabs>

With the default breakpoints. The max width is picked from each breakpoint’s editor viewport: **1200px** from 1440px, **960px** from 1024px, **728px** from 768px, and `none` below (only the values that differ from the inherited one are stored).

## Tips

- Containers are usually the only child of a Section: `Section > Container > content`.
- Change the max widths per breakpoint in **Size → Max W**.
