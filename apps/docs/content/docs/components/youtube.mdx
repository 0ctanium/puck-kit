**YouTube** embeds a video from any link: `watch?v=`, `youtu.be`, `shorts`, `live`, `embed` or a bare id; a `?t=` / `?start=` in the link becomes the start time. It is **16:9 and full width** by default, and uses **youtube-nocookie.com** (privacy-enhanced mode) unless you turn privacy off.

<Callout type="info" title="In the editor">
  Players never autoplay on the canvas and don’t catch clicks (`pointer-events: none`), so the element stays selectable. With an invalid link the editor shows a hint and the public page renders nothing.
</Callout>
