Use a **Section** for each horizontal band of a page (hero, features, testimonials, footer…). It is a plain element with a drop zone and **64px of padding above and below**. Put a [Container](/docs/components/container) inside to center the content.

## Tips

- Give the section a background (color, gradient or image) in **Backgrounds**; it spans the full width while the Container keeps the text readable.
- Pick `<header>`, `<main>` or `<footer>` as tag for the landmark sections of a page.
