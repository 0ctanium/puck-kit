**List Item** is an `<li>` with its own drop zone (24px tall when empty). Drop text, icons, images or whole layouts inside. Structural [states](/docs/styling/states) like *Odd children* or *Last child* are handy to stripe rows or remove the last separator.

## Props

Besides Puck’s `id`, the component stores these props (fields of the **Settings** tab, plus `tag`, `styles` and `advanced` in the **Style** tab):

## Default styles

None: a fresh List Item only gets the [base stylesheet](/docs/styling/css-output#the-base-stylesheet). Everything comes from the Style tab.

The example above uses the `base:odd` state for the striped background:

```json
{
  "base": {
    "display": "flex",
    "alignItems": "center",
    "gap": "12px"
  },
  "base:odd": {
    "backgroundColor": "var(--pk-color-surface)"
  }
}
```

## Tips

- A List Item can be dropped anywhere in the editor, but only renders valid HTML inside a List.
