**Text** is a `<div class="pk-rich">` with the **full rich text toolbar** — headings, lists, quotes, code blocks, rules. Use it for long-form content (articles, legal pages) or small labels inside layouts.

## Props

Besides Puck’s `id`, the component stores these props (fields of the **Settings** tab, plus `tag`, `styles` and `advanced` in the **Style** tab):

## Default styles

None: a fresh Text only gets the [base stylesheet](/docs/styling/css-output#the-base-stylesheet). Everything comes from the Style tab.

## Tips

- Styles set on the Text element (font, color, size) apply to everything inside; the rich text keeps semantic markup only.
