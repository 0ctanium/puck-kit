**Quote** renders a `<blockquote>` holding rich text (headings and nested quotes disabled). It starts italic, 20px, with 16px of left padding — add a left border for the classic look.

## Props

Besides Puck’s `id`, the component stores these props (fields of the **Settings** tab, plus `tag`, `styles` and `advanced` in the **Style** tab):

<TypeTable
  type={{
    text: {"type": "string (HTML)", "description": "Rich text (no headings, no nested blockquote).", "default": "\"<p>A memorable quote.</p>\""},
    styles: {"type": "Styles", "description": "Responsive, per-state styles edited in the Style tab. See [How styles work](/docs/styling)."},
    advanced: {"type": "Advanced", "description": "HTML `id`, extra classes and `aria-label` (Style tab → Advanced).", "default": "{}"},
  }}
/>

## Default styles

A freshly dropped Quote starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "paddingLeft": "16px",
    "fontStyle": "italic",
    "fontSize": "20px"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  padding-left: 16px;
  font-style: italic;
  font-size: 20px;
}
```

</Tab>
</Tabs>
