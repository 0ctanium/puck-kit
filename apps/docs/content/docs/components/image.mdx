**Image** renders an `<img>` (lazy-loaded by default, `decoding="async"`). Its source uses the kit’s [`image` field type](/docs/editor/field-types#image): a URL input with a preview out of the box, **your upload or media library** once you [override it](/docs/editor/overriding-fields). The screenshot shows the playground’s small media library.

## Props

Besides Puck’s `id`, the component stores these props (fields of the **Settings** tab, plus `tag`, `styles` and `advanced` in the **Style** tab):

<TypeTable
  type={{
    src: {"type": "string", "description": "Image URL (`image` field type).", "default": "\"\""},
    alt: {"type": "string", "description": "Alternative text for screen readers and SEO.", "default": "\"\""},
    loading: {"type": "\"lazy\" | \"eager\"", "description": "Lazy for images below the fold, eager for the hero image.", "default": "\"lazy\""},
    styles: {"type": "Styles", "description": "Responsive, per-state styles edited in the Style tab. See [How styles work](/docs/styling)."},
    advanced: {"type": "Advanced", "description": "HTML `id`, extra classes and `aria-label` (Style tab → Advanced).", "default": "{}"},
  }}
/>

## Default styles

A freshly dropped Image starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "display": "block",
    "maxWidth": "100%",
    "height": "auto"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  display: block;
  max-width: 100%;
  height: auto;
}
```

</Tab>
</Tabs>

<Callout type="info" title="Empty source">
  Without a `src`, the editor shows a gray placeholder and the public page renders nothing.
</Callout>

## Tips

- Use **Size → Ratio** and **Fit** (`object-fit: cover`) to crop images to a fixed shape.
