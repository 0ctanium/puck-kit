**Link Block** is an `<a>` with a drop zone: put headings, images or whole layouts inside to make them one link. To keep the HTML valid, it **refuses nested links**: Link Block, Button and Text Link can’t be dropped inside (`disallow`).

## Default styles

A freshly dropped Link Block starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tabs items={['styles (data)', 'compiled CSS']}>
<Tab value="styles (data)">

```json
{
  "base": {
    "display": "block",
    "color": "inherit",
    "textDecoration": "none"
  }
}
```

</Tab>
<Tab value="compiled CSS">

```css
.pk-id {
  display: block;
  color: inherit;
  text-decoration: none;
}
```

</Tab>
</Tabs>

<Callout type="warn" title="Editor behavior">
  In the editor, links don’t navigate and the Link Block’s attributes (`href`, `target`, `id`, `aria-label`) are only rendered on the public page.
</Callout>

## Tips

- Add a **Hover** state (border color, shadow, lift) so visitors see it is clickable.
