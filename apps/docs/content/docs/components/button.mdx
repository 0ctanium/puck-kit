**Button** renders an `<a>` (default) or a `<button type="button">`. The label is edited **inline on the canvas**. It ships with interaction [states](/docs/styling/states): it lifts on hover, shows a focus ring for keyboard users and presses down when clicked.

## Tips

- The colors are tokens (`Primary`, `White`): change the Primary token and every default button follows.
- Use the `button` tag for actions handled by your own scripts; use `a` for navigation.
