**Paragraph** holds rich text edited with Puck’s rich text editor: **bold**, *italic*, links, lists — but **no headings, quotes, code blocks or rules** (those toolbar options are disabled). Several paragraphs get a little space between them.

## Props

Besides Puck’s `id`, the component stores these props (fields of the **Settings** tab, plus `tag`, `styles` and `advanced` in the **Style** tab):

## Default styles

None: a fresh Paragraph only gets the [base stylesheet](/docs/styling/css-output#the-base-stylesheet). Everything comes from the Style tab.

<Callout type="info" title="Why a <div>?">
  The rich text output already contains real `<p>` elements, and a `<p>` can’t contain other `<p>`s. So Paragraph renders `<div class="pk-rich">` around them. The base stylesheet resets their margins and adds `0.75em` between consecutive blocks.
</Callout>

## Tips

- Need headings inside the text? Use [Text](/docs/components/text) instead.
