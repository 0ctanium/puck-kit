**V Flex** (“Vertical Flex”) is a Box preset with `display: flex; flex-direction: column` and a 16px gap. Children dropped inside stack vertically, evenly spaced; their own **Flex child** section appears in the Style tab.

## Tips

- Use it for text stacks (eyebrow, heading, paragraph, buttons): the gap replaces margins.
- Switch the direction to horizontal on one breakpoint only to turn a stack into a row on Desktop.
