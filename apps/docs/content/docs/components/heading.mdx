**Heading** is a title, `<h2>` by default (`<h1>`–`<h6>` in the Tag select). Its text is **plain and inline-editable** — type directly on the canvas. Size, weight and line height are styles, independent from the tag, so you can keep a correct outline (one `<h1>` per page) whatever the look.

## Default styles

A freshly dropped Heading starts with these `styles` — all editable, nothing is hard-coded in the render:

<Tab value="styles (data)">

```json
  "base": {
    "fontSize": "32px",
    "fontWeight": "700",
    "lineHeight": "1.2"
  }
}
```

## Tips

- Make big headings smaller on Mobile: select the Mobile breakpoint and change only the font size, everything else is inherited.
