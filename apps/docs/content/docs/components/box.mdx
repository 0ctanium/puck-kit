**Box** is the most generic element: a `<div>` — or `<section>`, `<article>`, `<aside>`, `<header>`, `<footer>`, `<nav>`, `<main>` — with a drop zone and **no default styles**. Section, Container, the Flex presets and Grid are all Boxes with different defaults.

## Default styles

None: a fresh Box only gets the [base stylesheet](/docs/styling/css-output#the-base-stylesheet). Everything comes from the Style tab.

## Tips

- Build cards, badges, dividers, overlays… anything that is “a styled element containing other elements”.
- Choose the semantic tag that matches the content (an `<article>` for a blog card, a `<nav>` for a menu).
