## Types

```ts
type StyleProp = (typeof STYLE_PROPS)[number]; // 'display' | 'flexDirection' | … | 'cursor'
type StyleDecl = Partial<Record<StyleProp, string>>;
type Styles = Record<string, StyleDecl | undefined>; // keys: 'base', 'tablet', 'base:hover'…
```

<Accordions type="single">
<Accordion title="STYLE_PROPS (emission order)">

| Group | Properties |
| --- | --- |
| Layout | `display`, `flexDirection`, `flexWrap`, `justifyContent`, `alignItems`, `alignContent`, `gap`, `rowGap`, `columnGap`, `gridTemplateColumns`, `gridTemplateRows`, `gridAutoFlow`, `justifyItems` |
| Child | `alignSelf`, `justifySelf`, `flexGrow`, `flexShrink`, `flexBasis`, `order`, `gridColumn`, `gridRow` |
| Spacing | `marginTop`, `marginRight`, `marginBottom`, `marginLeft`, `paddingTop`, `paddingRight`, `paddingBottom`, `paddingLeft` |
| Size | `width`, `minWidth`, `maxWidth`, `height`, `minHeight`, `maxHeight`, `aspectRatio`, `overflow`, `objectFit` |
| Position | `position`, `top`, `right`, `bottom`, `left`, `zIndex` |
| Typography | `fontFamily`, `fontSize`, `fontWeight`, `lineHeight`, `letterSpacing`, `color`, `textAlign`, `textTransform`, `textDecoration`, `fontStyle`, `whiteSpace`, `textShadow` |
| Background | `backgroundColor`, `backgroundImage`, `backgroundSize`, `backgroundPosition`, `backgroundRepeat`, `backgroundAttachment` |
| Border | `borderWidth`, `borderStyle`, `borderColor`, per-side `border{Top,Right,Bottom,Left}{Width,Style,Color}`, `borderRadius`, per-corner radii |
| Effects | `opacity`, `boxShadow`, `transform`, `transformOrigin`, `transition`, `filter`, `backdropFilter`, `mixBlendMode`, `cursor` |

Unitless (no automatic `px`): `flexGrow`, `flexShrink`, `order`, `zIndex`, `fontWeight`, `lineHeight`, `opacity`, `aspectRatio`.

## compileStyles

```ts
function compileStyles(
  selector: string,
  styles: Styles | null | undefined,
  breakpoints?: Breakpoint[], // defaultBreakpoints
  options?: CompileOptions,
): string;
```

<auto-type-table path="../../../../../packages/puck-kit/src/styles/compile.ts" name="CompileOptions" />

Emits the base block, then each breakpoint in emission order (base, `min-width` ascending, `max-width`
descending), each with its plain rules then its state rules, wrapped in `@media` when needed.

## declToCss

```ts
function declToCss(decl: StyleDecl | undefined): string; // "font-size:16px;color:red"
```

One declaration block, in `STYLE_PROPS` order, sanitized, with `px` added to bare numbers.

## resolveValue

```ts
function resolveValue(
  styles: Styles | null | undefined,
  prop: StyleProp,
  bpKey: string,
  breakpoints?: Breakpoint[],
  state?: string,
): { value: string | undefined; from: string | undefined; fromState?: string };
```

The effective value of a property at a breakpoint (and state), following the cascade — what the panel uses to
show inherited values.

## styleClass

```ts
styleClass('Heading-1a2b'); // "pk-Heading-1a2b" (unsafe characters become "_")
```

## States

```ts
interface StyleState { key: string; label: string; selector: string }
const defaultStates: StyleState[]; // hover, focus-visible, focus, focus-within, active, first-child, last-child, odd, even
function styleKey(breakpoint: string, state?: string): string; // "md" or "md:hover"
```

## getPageCss

```ts
function getPageCss(
  data: { root?: { props?: Record<string, unknown> }; content?: unknown; zones?: unknown },
  breakpoints?: Breakpoint[],
): string;
```

Base CSS + tokens + every element’s CSS (walks `content`, slots and `zones`; each id once).
→ [CSS output](/docs/styling/css-output#one-stylesheet-per-page)

## baseCss / editorCss

`baseCss` is the [base stylesheet](/docs/styling/css-output#the-base-stylesheet). `editorCss`
(`.pk-slot.pk-slot{width:auto;height:auto}`) undoes Puck’s drop-zone sizing on kit slots in the editor.
