## Stacks

| Function | Returns |
| --- | --- |
| `fontStack(font)` | CSS value: `font.stack`, or `"Family", <fallback>` (fallback from `fallback` or the category; generic names aren’t quoted) |
| `fontLabel(font)` | `font.label ?? font.family` |
| `fontWeights(font)` | Sorted weights, default `[400, 700]` |
| `firstFamily(stack)` | The first family of a stack, unquoted and lowercased |
| `findFont(stack, library)` | The library font a stack refers to |
| `systemFonts` | 8 system stacks (always offered in pickers) |

## FontLinks

```tsx
<FontLinks fonts={fonts} />        // hoisted <link precedence> + @font-face, preconnect to Google
<FontLinks fonts={fonts} inline /> // in place (for an iframe)
```

The root renders it from `metadata.pkFonts`; use it directly in custom layouts. Server-safe.
