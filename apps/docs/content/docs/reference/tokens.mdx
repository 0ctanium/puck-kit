```ts
interface Token { name: string; value: string }
interface Tokens { colors?: Token[]; fonts?: Token[]; sizes?: Token[] }
```

| Function | Example | Result |
| --- | --- | --- |
| `tokenVar(kind, name)` | `tokenVar('colors', 'Brand Blue')` | `--pk-color-brand-blue` |
| `tokenRef(kind, name)` | `tokenRef('sizes', 'LG')` | `var(--pk-size-lg)` |
| `tokensToCss(tokens)` | `tokensToCss({ colors: [{ name: 'Primary', value: '#4f46e5' }] })` | `:root{--pk-color-primary:#4f46e5}` |

Prefixes: `colors` → `color`, `fonts` → `font`, `sizes` → `size`. Names are slugified (lowercase, non-alphanumerics
become `-`). Tokens without a name or value are skipped; values are sanitized like style values.
